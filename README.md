# 便携加密保险箱（SecureVault）

当前版本：**v1.0.0**

一个类似 SanDisk SecureAccess 的本地加密工具，但**不限制硬件**：U 盘、移动硬盘、电脑本地目录都能用。

- **免安装**：打包成单个 `VaultApp.exe`，双击即用，不写注册表、不建系统服务
- **便携**：保险箱数据与程序放在同一目录，整个文件夹拷到 U 盘即可带走
- **真加密**：AES-256-GCM 认证加密 + Argon2id 口令派生，文件名与目录名也不会明文落盘

---

## 快速开始

1. 运行 `dist\VaultApp.exe`
2. 首次使用输入两次主密码（至少 8 位），点击「创建保险箱」
3. 之后每次打开输入主密码解锁

创建完成后，程序同级目录会出现 `vault\` 文件夹，这就是你的加密保险箱。

> **移动到 U 盘**：把 `VaultApp.exe` 和同目录下的 `vault\` 一起复制过去即可，路径无需配置。

## 使用说明

### 当前文件夹与取消选择

「新建文件夹」「添加文件」「拖放导入」都以**当前选中的文件夹**为目标：

- 点击文件夹行：该文件夹成为目标，新建 / 导入的内容都会落在它里面
- 点击文件行：目标回到保险箱根目录
- 点击列表空白处或按 `Esc`：取消选择，目标同样回到根目录

> 如果发现新建的内容总是跑进某个子文件夹，通常是该文件夹仍处于选中状态；点一下列表空白处或按 `Esc` 即可回到根目录。

### 拖放导入

- 文件拖入：保存到当前选中的文件夹（未选中文件夹时为根目录）
- 文件夹拖入：保留完整目录结构
- 支持一次拖入多个项目；同名文件会自动重命名为 `名字 (1).扩展名`

### 排序与搜索

- **排序**：点击「名称」「大小」「修改时间」表头即可排序，当前排序列会显示 ▲ / ▼ 方向标记；再次点击同一列切换升 / 降序，切换列时默认升序。文件夹始终排在文件前面；按大小或时间排序时，文件夹内部仍按名称排列。
- **搜索**：在顶部搜索框输入关键字即可实时过滤，匹配范围是文件 / 文件夹的相对路径（因此文件名、文件夹名都能搜到，命中文件夹时其内容一并显示），命中项的上级目录会自动展开。
  - 状态栏显示匹配到的文件 / 文件夹数量，无匹配时列表为空
  - 点击「清除」或按 `Esc` 恢复完整目录树
  - 搜索状态下仍可正常排序、新建、导出等操作

### 双击打开与自动回存

双击文件时，程序把它解密到程序目录下的 `.vault_open\` 缓存目录，再交给系统默认程序。你编辑并保存后：

- 点击「锁定」或关闭窗口时，程序比对文件大小与修改时间，把改动重新加密写回保险箱
- 若文件仍被其他程序独占打开导致回存失败，会弹窗列出这些文件
- 明文缓存目录会在锁定、退出和下次启动时清理

> 需要「另存为」或引用相对路径的程序，建议改用「导出」功能。

### 自动锁定

界面右下角显示倒计时。任何鼠标移动、按键、点击都会重置计时。保险箱锁定后，密钥从内存中清除，需要重新输入密码。

## 安全设计

### 密钥体系

```text
主密码 --Argon2id(64 MiB, t=3, p=2)--> KEK（仅内存）
随机 DEK(32B) --AES-256-GCM 包装--> wrapped_dek（写入 meta.json）
DEK --HKDF-SHA256--> index_key / content_key
```

- **DEK 包装**：文件内容始终用同一把随机 DEK 加密，改主密码时只用新 KEK 重新包装 DEK，因此改密是 O(1)，与保险箱大小无关
- **Argon2id**：64 MiB 内存开销，显著提高离线暴力破解成本
- **子密钥隔离**：索引和文件内容使用 HKDF 派生的不同子密钥，互不影响

### 数据加密

- 每个文件独立随机 nonce，AES-256-GCM 认证加密
- **1 MiB 分块流式处理**，加密几个 GB 的大文件也不会占满内存
- **AAD 绑定文件 ID**：把密文互相调换会导致认证失败，无法蒙混过关
- 索引文件 `index.enc` 同样整体加密，因此**文件名、目录名都不以明文落盘**

### 其他

- 元数据写入使用「临时文件 + fsync + 原子替换」，避免断电导致索引损坏
- 删除文件时先用随机数据覆写再删除，降低被恢复的可能
- 路径片段会清洗非法字符并拒绝 `..`，防止越权写入

### 已知限制

- **忘记密码即无法恢复**：没有后门、没有找回渠道，请务必牢记密码或离线备份
- 保险箱解锁期间，双击打开的文件在程序目录的 `.vault_open\` 缓存中是明文；程序会在锁定/退出时清理，但异常断电等情况下可能有残留
- SSD / 闪存存在磨损均衡，覆写删除不能保证物理擦除
- 加密只保护 `vault\` 内的数据；**程序本身和元数据文件可以被复制**，安全性完全依赖密码强度

## 保险箱目录结构

```text
SecureVault/
├── VaultApp.exe        程序（单文件）
├── .vault_open/        双击打开时的明文缓存（锁定/退出时自动清空）
└── vault/              保险箱
    ├── meta.json       明文元数据：KDF 参数、盐、被包装的 DEK
    ├── index.enc       加密索引：文件夹层级 + 相对路径 / 大小 / 修改时间
    └── data/
        └── <前两位>/
            └── <随机ID>.bin 每个文件独立加密，文件名即随机 ID，按 ID 前两位分片
```

`meta.json` 中不含密码，也不含可用于解密的密钥；没有正确主密码无法还原出 DEK。

## 从源码运行

需要 Python 3.10+（开发环境为 3.13），并保证 Python 自带 tkinter。

```bash
python -m pip install -r requirements.txt
python vault_app.py
```

依赖：

- `cryptography` — AES-256-GCM、HKDF
- `argon2-cffi` — Argon2id 口令派生
- `tkinterdnd2` — 拖放支持
- `pyinstaller` — 打包（仅构建时需要）

## 打包

### Windows

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

产物：`dist\VaultApp.exe`

### Linux

```bash
sudo apt-get install -y python3 python3-venv python3-tk
bash build.sh
```

产物：`dist/VaultApp`

> PyInstaller 不支持交叉编译，Linux 版本必须在 Linux 上构建；产物兼容性与构建环境的 glibc 版本相关。

打包注意事项：

- 打包前先关闭正在运行的 `VaultApp.exe`，否则 `dist\VaultApp.exe` 会被占用导致构建失败
- **不要删除 `dist\vault\`**，那是实际的保险箱数据

## 常见问题

**Q：笔记本上界面模糊，台式机正常？**  
A：已修复。程序会在创建窗口前声明进程 DPI 感知，并按显示器真实 DPI 设置 Tk 缩放，125% 缩放下也保持清晰。

**Q：双击文件后修改了内容，但没保存就锁定了？**  
A：程序会在锁定时比对文件状态并自动回存已保存的改动。若文件仍被其他程序占用，会提示回存失败。

**Q：把 exe 发给别人，对方能打开我的保险箱吗？**  
A：能打开程序，但没有主密码无法解密。建议不要把含真实数据的 `vault\` 一并分享。

**Q：能不能放在网盘同步目录？**  
A：可以，但多个设备同时解锁写同一份保险箱可能造成索引冲突，建议单设备使用或手动同步。

**Q：保险箱有容量上限吗？**  
A：没有硬性上限，受存储设备剩余空间限制。单文件采用流式加密，不做大小限制。

**Q：新建文件夹 / 导入的文件总是进到某个子文件夹里？**  
A：目标目录跟随当前选中的文件夹。点击文件行、点击列表空白处或按 `Esc` 都可以让目标回到根目录后再新建 / 导入。

**Q：搜索会不会看到明文内容？**  
A：不会。搜索只匹配保险箱内已解密的文件名和目录名，不会读取或上传文件内容；重新解锁时搜索条件会自动清空。
